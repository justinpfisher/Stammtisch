After saving, copy the entire saved editor file back into this verifier and compare it. Keep the original deployment, private-only files, properties, manifest, and trigger unchanged.
  4. After all seven match, update the existing Apps Script web-app deployment, then independently read back non-secret settings, affected functionality, and the next natural trigger run. This verifier does not prove that a deployment went live.

Do not paste credentials, private originals, member data, or Script Properties. Select only the seven reviewed public modules. Abort if the signed-in editor project, existing source, or private-only code differs unexpectedly.
