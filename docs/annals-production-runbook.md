## Cocktail images and other photographs

Eligible input formats are JPEG, PNG, WebP, HEIC and HEIF; real private acceptance for the latter four has not yet been demonstrated. Apply the existing installed conversion/screening safeguards and source rights before public output, strip metadata and preserve orientation. Publish a screened authentic original rather than a fabricated photographic edit if the optional transformation fails.

**The US$2/photo reservation rule is retired.** The already owner-verified provider project-enforced **US$5/month hard cap** is the monetary boundary. The #247 source was installed and read back in Version 58, preserving historical private reservations. A paid operation needs an eligible source-bound signed permission, an existing restricted image credential and verified cap, and one exclusive durable attempt marker in the canonical private output directory. The first supervised Kingston orchard editorial photograph was owner-accepted and published in [#322](https://github.com/justinpfisher/Stammtisch/pull/322), preserving the original source.
